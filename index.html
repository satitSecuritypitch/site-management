ผังความเชื่อมโยงของ Site

Site อยู่ตรงกลาง สัญญาและไฟล์ชี้มาที่ site ส่วน site ไม่เก็บรายการสัญญาหรือไฟล์ไว้เอง ค่าบางตัวที่ API ส่งออกคำนวณตอนอ่าน

1. ข้อมูลเชื่อมกันอย่างไร

2. ตอนสร้าง site ลำดับการทำงาน

3. ตัวแปรของ site

ตัวแปรชนิด / ค่าที่ใช้ได้เก็บหรือคำนวณกฎและที่มา
_idObjectId (ส่งออกเป็น id)เก็บถูกอ้างจาก contracts.site_id และ files.links.site
organization_idstringเก็บทุก query กรองตามองค์กรจาก token
site_code1–50 ตัว: A–Z 0–9 _ -เก็บส่งเองได้ ไม่งั้นได้ SITE-{ปี}-{ลำดับ} ไม่ซ้ำในองค์กรที่ยังไม่ถูกลบ
namestring 1–255เก็บจำเป็น ค้นหาได้
typeHIGH_RISE_RESIDENTIAL · COMMERCIAL_MALL · INDUSTRIAL_LOGISTICS · INFRASTRUCTURE หรือ nullเก็บกรองได้ ไม่บังคับ
addressstring สูงสุด 1000เก็บค้นหาได้
locationAPI: {lat, lng} · DB: GeoJSON Pointเก็บค่า lat −90…90, lng −180…180; มี index GEOSPHERE
start_date / end_datedateเก็บไม่บังคับ; end ต้องไม่ก่อน start (ตรวจเฉพาะใน site เอง)
status (เก็บ)ACTIVE · COMPLETEDเก็บPATCH ได้ ไม่มี NEAR_CLOSE ในฐานข้อมูล
status (ตอบกลับ)ACTIVE · NEAR_CLOSE · COMPLETEDคำนวณจาก end_date และ NEAR_CLOSE_DAYS (ค่าเริ่มต้น 90) ไม่มี end_date = ACTIVE; end_date ที่ผ่านไปแล้วเป็น COMPLETED
contract_countintคำนวณนับ contracts ที่ยังไม่ถูกลบ ทุกครั้งที่อ่าน
total_contract_valuenumber (Decimal)คำนวณรวม contract_value ของสัญญาทั้งหมดของ site
created / updated / deleted _at, _bydatetime, stringเก็บทุกการเขียนบันทึก actor จาก token; ลบเป็น soft delete

4. วงจรชีวิตของ site

5. แต่ละ API อ่านและเขียนอะไรบ้าง

Endpointอ่านเขียนหมายเหตุ
GET /sitessites, contracts (นับและรวมค่า)—กรองด้วย status, type, date_from / date_to, search (search รวมชื่อสัญญาด้วย)
GET /sites/{id}sites, contracts, files (links.site)—ไม่พบหรือถูกลบแล้ว ได้ 404
POST /sites/previewcontracts (เลขซ้ำ), vendors (ชื่อ), counters—ไม่เลื่อนเลข counter และไม่บันทึกอะไร
POST /sitescontracts, vendors, files, counterssites, vendors (ใหม่), contracts, files (links)counter เลื่อนก่อนเข้า transaction ที่เหลืออยู่ใน transaction เดียว
PATCH /sites/{id}sitessites (เฉพาะฟิลด์ที่ส่งมา)ตรวจ end_date ไม่ก่อน start_date ไม่แตะสัญญาหรือไฟล์
DELETE /sites/{id}contracts (นับที่ยังไม่ถูกลบ)sites, files (links.site) ทั้งหมด (soft delete)มีสัญญาอยู่ได้ 409; ไฟล์ที่ผูกไว้ถูก soft delete ด้วย (S3 คงไว้)
POST /sites/ocrไฟล์ที่ส่งมา—อ่านแล้วคืนค่า ไม่บันทึก
POST /sites/attachments/{id}/ocrfilesfiles (ocr_*)ไม่แตะ site
GET /sites/attachment-categoriesค่าคงที่—4 หมวด: MAIN_CONTRACT, BOQ, SITE_SAFETY_PLAN, OTHER
